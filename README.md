# UP · Mac 公开测试版

UP 是一个 Mac 菜单栏深蹲提醒工具。到点后用 iPhone 扫码，手机本地识别和计数，完成后 Mac 收到回执。

[打开 UP 网页](https://up.tcliu.cc) · [查看发布版本](https://github.com/tianchengliu18/up-downloads/releases)

## 系统要求

Apple 芯片 Mac，macOS 14 或更新版本。iPhone 扫码使用 Safari。

下载 Release 的 Assets 里的安装包，解压后将 UP.app 移到「应用程序」并打开。UP 目前是公开测试版，采用临时签名。首次打开时 macOS 可能提示无法验证开发者。请核对下载来源和发布说明中的 SHA-256。 [Apple 关于安全打开 App 的说明](https://support.apple.com/zh-cn/102445)

这个仓库用于提供安装包和发布说明。
